## 自动登录

- 新增“记住账号并自动登录”，在设置中输入邮箱或学号、密码，选择“保存并开启”即可使用。
- 登录过期后，打开 App 或刷新考勤时会尝试自动登录，成功后返回 App 并刷新考勤。
- 账号密码仅在本机加密保存，不进入日志或备份，不发送至学校以外的服务器；可随时关闭自动登录或清除保存的账号密码。
- 遇到验证码、二次验证或登录失败时停止自动尝试，需要手动处理。自动登录默认关闭。

## 应用内更新

- 更新检查优先读取静态版本清单，减少校园网共享出口触发 GitHub API 限流的影响。
- 修复版本信息未变化时可能错误显示“已是最新版”的问题，保留可用新版本提示。
- 下载后继续校验安装包完整性和签名，修复 Android 8 的安装包校验兼容性。

## 安装与使用

下载 `slaier-1.2.0.apk` 覆盖安装即可，无需卸载旧版。包内版本为 1.2.0，versionCode 为 9。

如需自动登录，请进入 **设置 → 记住账号并自动登录 → 保存并开启**。学校要求的验证码或二次验证仍需本人完成。
